Description: 
"Weather Beware" is a website that displays the temperature range, from the highest to the lowest, in Fahrenheit and the max precipitation chance for the day based on the city the user has entered.

How to run: 
First, the user enters the city they liked to know the weather about in the text box and click the submit button. After the submission, the date of how the weather is, the temperature range, and max precipitation chance is displayed on screen for the user to read.

Data source credits:

OpenMeteo for weather data: https://open-meteo.com/en/docs
OpenMeteo for city location: https://open-meteo.com/en/docs/geocoding-api
